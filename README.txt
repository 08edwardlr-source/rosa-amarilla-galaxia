ROSA AMARILLA ENTRE GALAXIAS
============================

EJECUCIÓN RÁPIDA
1. Descomprime el archivo ZIP.
2. Abre la carpeta "rosa-amarilla-galaxia".
3. Haz doble clic en index.html.

No necesita Python ni instalar programas. Funciona en Chrome, Edge y Opera.

INTERACCIONES
- Mueve el mouse: la rosa responde con profundidad 3D.
- Haz clic en el fondo: crea una onda de luz.
- Botón "Pide un deseo": explosión de partículas doradas.
- Botón ✦: aumenta los destellos y genera meteoros.
- Botón ⛶: pantalla completa.
- Botón ♪: activa un ambiente sonoro suave creado en el navegador.

ARCHIVOS
- index.html: estructura principal.
- styles.css: diseño, adaptación móvil y animaciones.
- script.js: galaxia, estrellas, meteoros e interacción.
- assets/rosa-amarilla-realista.png: imagen fotorrealista de la rosa.

Para personalizar el mensaje, abre index.html con Bloc de notas o VS Code y
edita el título y el párrafo dentro de la sección con class="message".
